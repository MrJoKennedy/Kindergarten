# SQL-скрипты базы данных «Дошкольный центр развития ребёнка»

СУБД: **PostgreSQL 15 и новее** (разрабатывалось под PostgreSQL 18). Все объекты создаются в схеме `center`.
Кодировка базы данных — **UTF8** (в данных и ограничениях есть русские буквы).

> Скрипты написаны для PostgreSQL и проверены на внутреннюю согласованность, но на живом сервере PostgreSQL
> автором не запускались. Если при выполнении появится ошибка — скопируйте её текст и исправьте указанную строку.

## Что где лежит

### 01_structure — создание структуры базы данных (лабораторные работы №6–7)

| Файл | Что делает |
|------|------------|
| `create_db.sql` | **Главный скрипт.** Создаёт схему `center`, 8 доменов, 17 таблиц с ключами и ограничениями, 16 индексов, 11 триггеров и 3 представления |
| `01_schema_domains.sql` … `05_views.sql` | То же самое, разбитое на части: схема и домены → таблицы → индексы → триггеры → представления. Нужны, если хочется выполнять по шагам. Выполнять строго по порядку |
| `drop_db.sql` | Удаляет схему `center` целиком (`DROP SCHEMA center CASCADE`). Нужен для повторного создания с нуля |
| `check_structure.sql` | Запросы к системным каталогам: список таблиц, столбцов, доменов, ограничений, индексов, триггеров, представлений. Ожидается: 17 таблиц, 75 столбцов, 8 доменов; ограничения p = 17, f = 19, u = 6, c = 8; 39 индексов; 11 триггеров; 3 представления |
| `ddl_examples.sql` | Примеры команд изменения структуры (`ALTER TABLE`, `CREATE/DROP INDEX`, `ALTER DOMAIN`, временная таблица) с командами отмены. Для защиты лабораторной №7; **выполнять по одному блоку**, а не целиком |

### 02_data — заполнение данными (лабораторная работа №8)

| Файл | Что делает |
|------|------------|
| `fill_data.sql` | **Основной набор данных:** 2128 записей во всех 17 таблицах (вымышленные дети, родители, педагоги, группы, расписание, оплаты, посещаемость). Сначала очищает таблицы (`TRUNCATE ... RESTART IDENTITY`), затем вставляет данные в одной транзакции и настраивает счётчики. Запускать после `create_db.sql` |
| `seed_data.sql` | Маленький демонстрационный набор (1 ребёнок, 1 группа) из лабораторной №7. Нужен только для быстрой проверки. **Не запускайте его вместе с `fill_data.sql`:** выберите что-то одно |
| `insert_examples.sql` | Примеры ручных `INSERT`: одна запись, транзакция с несколькими связанными записями, `INSERT ... SELECT`. Запускать после `fill_data.sql` |
| `generate_data.py` | Python-программа, которая создаёт `fill_data.sql` (нужен Python 3 и пакет `python-dateutil`: `pip install python-dateutil`). Нужна, только если хотите сгенерировать другие данные: `python generate_data.py` |

### 03_queries — запросы (лабораторные работы №8–9)

| Файл | Что делает |
|------|------------|
| `queries_lab8.sql` | 36 запросов `SELECT` (и вариант с `FETCH FIRST`): выбор столбцов, `AS`, `ORDER BY`, `WHERE`, `AND/OR/NOT`, `IS NULL`, `IN`, `BETWEEN`, `LIKE`, `DISTINCT`, `LIMIT/OFFSET`, `FETCH FIRST` |
| `queries_lab9.sql` | 50 запросов с вычислениями и группировкой: арифметика, математические, строковые функции, функции даты, `CASE`, `COALESCE`, `GROUP BY`, `HAVING`. Запросы с `CURRENT_DATE` и `NOW()` дают разный результат в зависимости от даты |
| `test_constraints.sql` | 8 запросов, **каждый из которых должен завершиться ошибкой**: так проверяется, что ограничения целостности работают (домены, `UNIQUE`, внешние ключи, триггеры). Выполнять по одному после заполнения базы |

## Как правильно запустить

### Вариант 1. Командная строка (psql)

```bash
# 1. создать пустую базу данных в кодировке UTF8
createdb -U postgres -E UTF8 --template=template0 kindergarten_center

# 2. создать структуру
psql -U postgres -d kindergarten_center -f 01_structure/create_db.sql

# 3. проверить, что всё создалось
psql -U postgres -d kindergarten_center -f 01_structure/check_structure.sql

# 4. заполнить данными
psql -U postgres -d kindergarten_center -f 02_data/fill_data.sql

# 5. выполнить запросы
psql -U postgres -d kindergarten_center -f 03_queries/queries_lab8.sql
psql -U postgres -d kindergarten_center -f 03_queries/queries_lab9.sql
```

В Windows, если русские буквы отображаются неправильно, перед запуском выполните `chcp 65001` и добавьте
в psql команду `\encoding UTF8` (или переменную `set PGCLIENTENCODING=UTF8`).

### Вариант 2. pgAdmin

1. Правой кнопкой по **Databases → Create → Database…**, имя `kindergarten_center`, вкладка *Definition*: Encoding = `UTF8`, Template = `template0`.
2. Откройте базу → **Tools → Query Tool** → значок «Open File» → выберите `create_db.sql` → **F5** (Execute).
3. Так же последовательно откройте и выполните `fill_data.sql`, затем нужные запросы.
4. Для запросов из `queries_lab8.sql` и `queries_lab9.sql` выделяйте **один запрос** и нажимайте F5 — pgAdmin показывает результат только последнего оператора из всего выполненного фрагмента.

### Порядок запуска (коротко)

1. `01_structure/create_db.sql`
2. `01_structure/check_structure.sql` (проверка)
3. `02_data/fill_data.sql` (или `seed_data.sql`)
4. `03_queries/*` — по желанию, в любом порядке
5. `03_queries/test_constraints.sql` — по одному запросу, каждый должен дать ошибку

### Повторный запуск с нуля

```bash
psql -U postgres -d kindergarten_center -f 01_structure/drop_db.sql
psql -U postgres -d kindergarten_center -f 01_structure/create_db.sql
psql -U postgres -d kindergarten_center -f 02_data/fill_data.sql
```

## Что учитывать

- **Транзакция и отложенные триггеры.** У ребёнка должен быть хотя бы один родитель, у программы — хотя бы одно направление, у педагога — хотя бы одна специализация. Эти правила проверяются при `COMMIT`, поэтому связанные записи нужно добавлять в одной транзакции (`BEGIN … COMMIT`), как сделано в `fill_data.sql` и `insert_examples.sql`.
- **Возраст ребёнка** считается в полных месяцах: «до 7 лет» — не старше 7 лет 0 месяцев (84 месяца), «1,5 года» — 18 месяцев.
- **Ключи identity.** В `fill_data.sql` значения ключей заданы явно, а после `COMMIT` счётчики переустановлены командой `ALTER TABLE … RESTART WITH`, поэтому новые записи получают следующие номера без конфликтов.
- **Типичные ошибки.**
  - `relation "..." does not exist` — не выполнен `create_db.sql` или не задана схема: выполните `SET search_path TO center;`.
  - `schema "center" already exists` / `type "d_phone" already exists` — структура уже создана: выполните сначала `drop_db.sql`.
  - `invalid byte sequence` / вместо русских букв «кракозябры» — неправильная кодировка: создайте базу в UTF8 и задайте `client_encoding`.
  - `У ребёнка ... не указан ни один родитель` — родитель и ребёнок добавлялись в разных транзакциях.
